### What I do

- **Web apps, front to back** — React / Next.js on the client, Node.js / Express on the server, PostgreSQL and Supabase for data
- **AI-powered features** — LLM integrations (OpenAI, Claude) designed into real product flows, not bolted on
- **Web, mobile & desktop** — PWA and Expo native apps sharing one API, Electron desktop tools, WebGL games
- **Data pipelines** — scheduled scrapers and publishing jobs that turn public data into product content
- **Ad-tech domain** — creative tooling and marketing data products
